# ⚙️ Digital RPM Meter Using Arduino Nano

> A compact, low-cost and real-time rotational speed measurement system using Arduino Nano, IR sensor and 16×2 I2C LCD.

## 📌 Overview

The **Digital RPM Meter** is an embedded electronics project designed to measure the rotational speed of a motor or rotating object in **Revolutions Per Minute (RPM)**.

The system uses an **IR sensor** to detect each rotation of a rotating object. The sensor generates digital pulses, which are processed by an **Arduino Nano based on ATmega328P**.

The Arduino counts the pulses within a fixed time interval and calculates the RPM. The measured value is then displayed in real time on a **16×2 LCD through an I2C interface**.

An LED indicator is also used to provide visual feedback during pulse detection.

🧮 Calculations

The Digital RPM Meter calculates the rotational speed by counting the pulses generated by the IR sensor within a fixed time interval.

When one pulse represents one complete rotation, the RPM is calculated using:

RPM = Pulses detected in 1 second × 60

Example

If the IR sensor detects 25 pulses in 1 second:

RPM = 25 × 60
RPM = 1500 RPM

Where:

Pulse = One complete rotation detected by the IR sensor

1 second = Fixed pulse-counting interval

60 = Conversion factor from seconds to minutes


The calculated RPM is displayed on the 16×2 LCD in real time.

⚠️ Limitations

Strong sunlight or external infrared light may affect sensor performance.

Dust or dirt on the sensor or reflective surface may cause incorrect readings.

The IR sensor has a limited detection range.

Correct sensor alignment with the reflective surface is required.

Extremely high-speed rotation may be difficult to measure with the basic setup.

Voltage fluctuations can affect system operation.

The basic system is designed for one rotating object at a time.

The circuit does not include protective casing for harsh industrial environments.

Moisture and vibration protection is limited.


These limitations are listed in the project's Disadvantages section.
